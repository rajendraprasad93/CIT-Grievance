**Required Database Schema:**
```sql
CREATE TABLE aggregated_issues (
    agg_id TEXT PRIMARY KEY,
    title TEXT NOT NULL,
    ai_summary TEXT NOT NULL,
    severity TEXT NOT NULL,
    related_count INTEGER DEFAULT 0,
    total_comments INTEGER DEFAULT 0,
    total_affected INTEGER DEFAULT 0,
    sentiment REAL DEFAULT 0,
    category TEXT NOT NULL,
    locations TEXT DEFAULT '[]',
    status TEXT DEFAULT 'reported',
    trend TEXT DEFAULT 'stable',
    related_issue_ids TEXT DEFAULT '[]',
    last_activity TEXT,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL
);

CREATE TABLE issue_clusters (
    cluster_id TEXT PRIMARY KEY,
    agg_id TEXT NOT NULL,
    issue_id TEXT NOT NULL,
    similarity_score REAL,
    clustered_at TEXT NOT NULL,
    FOREIGN KEY (agg_id) REFERENCES aggregated_issues(agg_id),
    FOREIGN KEY (issue_id) REFERENCES issues(issue_id)
);
```

### What Works Today
- ✅ Admin can log in with `role: 'admin'`
- ✅ Frontend access control checks `user.role === 'admin'`
- ✅ Admin can view all issues from database
- ✅ Admin can update issue status (acknowledge, start work, resolve)
- ✅ Issue status endpoint has admin role check
- ✅ Basic counts for issues, moments, opportunities

### Critical Blockers

1. **No AI Services**
   - AI issue aggregation is 100% mock data
   - AI content moderation is 100% mock data
   - No clustering, sentiment analysis, or risk detection

2. **No Moderation Backend**
   - Approve/Remove/Review actions only update local state
   - No persistence of moderation decisions
   - No audit trail for moderation actions

3. **No Admin Middleware**
   - Only one endpoint (`PUT /api/issues/{id}/status`) checks admin role
   - No centralized admin route protection
   - Other admin endpoints don't exist

4. **No Audit Logging**
   - Admin actions are not logged
   - No accountability trail
   - Security compliance gap

### Missing Dependencies

1. **AI/ML Infrastructure**
   - Text clustering algorithm (for issue aggregation)
   - Sentiment analysis model
   - Content classification model (for risk categories)
   - Confidence scoring system

2. **Database Tables**
   - `aggregated_issues`
   - `issue_clusters`
   - `flagged_content`
   - `moderation_log`
   - `audit_logs`
   - `system_config`

3. **Services**
   - AI Clustering Service
   - AI Content Analysis Service
   - Audit Logging Service
   - Admin Statistics Service

### Security Gaps

| Gap | Severity | Impact |
|-----|----------|--------|
| No admin middleware | HIGH | Any authenticated user could potentially access admin APIs if they existed |
| No audit logging | HIGH | No accountability for admin actions |
| No rate limiting on admin endpoints | MEDIUM | Potential for abuse |
| No IP restriction for admin access | LOW | Admin accessible from any location |
| Moderation actions not persisted | HIGH | Decisions lost on page refresh |
| No two-factor auth for admin | MEDIUM | Single point of authentication failure |

### Recommended Implementation Order

1. **Phase 1 (Security Foundation):** 
   - Create admin middleware
   - Implement audit logging

## Complete Database Schema Additions Required

```sql
-- ============ AI ISSUE AGGREGATION ============

CREATE TABLE aggregated_issues (
    agg_id TEXT PRIMARY KEY,
    title TEXT NOT NULL,
    ai_summary TEXT NOT NULL,
    severity TEXT NOT NULL CHECK (severity IN ('critical', 'high', 'medium', 'low')),
    related_count INTEGER DEFAULT 0,
    total_comments INTEGER DEFAULT 0,
    total_affected INTEGER DEFAULT 0,
    sentiment REAL DEFAULT 0,
    category TEXT NOT NULL,
    locations TEXT DEFAULT '[]',
    status TEXT DEFAULT 'reported',
    trend TEXT DEFAULT 'stable' CHECK (trend IN ('increasing', 'stable', 'decreasing')),
    related_issue_ids TEXT DEFAULT '[]',
    last_activity TEXT,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL
);

CREATE TABLE issue_clusters (
    cluster_id TEXT PRIMARY KEY,
    agg_id TEXT NOT NULL,
    issue_id TEXT NOT NULL,
    similarity_score REAL,
    clustered_at TEXT NOT NULL,
    FOREIGN KEY (agg_id) REFERENCES aggregated_issues(agg_id),
    FOREIGN KEY (issue_id) REFERENCES issues(issue_id),
    UNIQUE(agg_id, issue_id)
);

-- ============ CONTENT MODERATION ============

CREATE TABLE flagged_content (
    flag_id TEXT PRIMARY KEY,
    post_id TEXT NOT NULL,
    post_type TEXT NOT NULL CHECK (post_type IN ('moment', 'comment', 'announcement', 'issue')),
    content TEXT NOT NULL,
    author_id TEXT NOT NULL,
    author_name TEXT NOT NULL,
    author_role TEXT,
    classroom TEXT,
    department TEXT,
    risk_category TEXT NOT NULL CHECK (risk_category IN ('harassment', 'hate_speech', 'self_harm', 'bullying', 'misinformation', 'policy_violation', 'spam', 'other')),
    risk_severity TEXT NOT NULL CHECK (risk_severity IN ('critical', 'high', 'medium', 'low')),
    confidence_score REAL NOT NULL CHECK (confidence_score >= 0 AND confidence_score <= 1),
    ai_reasoning TEXT,
    status TEXT DEFAULT 'pending' CHECK (status IN ('pending', 'approved', 'removed', 'reviewed')),
    reviewed_by TEXT,
    reviewed_at TEXT,
    flagged_at TEXT NOT NULL,
    interactions_likes INTEGER DEFAULT 0,
    interactions_comments INTEGER DEFAULT 0,
    FOREIGN KEY (author_id) REFERENCES users(user_id)
);

CREATE TABLE moderation_log (
    log_id TEXT PRIMARY KEY,
    flag_id TEXT NOT NULL,
    post_id TEXT NOT NULL,
    action TEXT NOT NULL CHECK (action IN ('approved', 'removed', 'reviewed', 'escalated')),
    admin_id TEXT NOT NULL,
    admin_name TEXT NOT NULL,
    reason TEXT,
    timestamp TEXT NOT NULL,
    FOREIGN KEY (flag_id) REFERENCES flagged_content(flag_id),
    FOREIGN KEY (admin_id) REFERENCES users(user_id)
);

-- ============ AUDIT LOGGING ============

CREATE TABLE audit_logs (
    log_id TEXT PRIMARY KEY,
    admin_id TEXT NOT NULL,
    admin_name TEXT NOT NULL,
    action_type TEXT NOT NULL,
    entity_type TEXT NOT NULL,
    entity_id TEXT NOT NULL,
    old_value TEXT,
    new_value TEXT,
    ip_address TEXT,
    user_agent TEXT,
    timestamp TEXT NOT NULL,
    FOREIGN KEY (admin_id) REFERENCES users(user_id)
);

-- ============ SYSTEM CONFIGURATION ============

CREATE TABLE system_config (
    config_key TEXT PRIMARY KEY,
    config_value TEXT NOT NULL,
    config_type TEXT DEFAULT 'string',
    description TEXT,
    updated_by TEXT,
    updated_at TEXT NOT NULL
);

-- ============ INDEXES ============

CREATE INDEX idx_aggregated_issues_severity ON aggregated_issues(severity);
CREATE INDEX idx_aggregated_issues_status ON aggregated_issues(status);
CREATE INDEX idx_aggregated_issues_category ON aggregated_issues(category);
CREATE INDEX idx_issue_clusters_agg ON issue_clusters(agg_id);
CREATE INDEX idx_issue_clusters_issue ON issue_clusters(issue_id);
CREATE INDEX idx_flagged_content_status ON flagged_content(status);
CREATE INDEX idx_flagged_content_severity ON flagged_content(risk_severity);
CREATE INDEX idx_flagged_content_category ON flagged_content(risk_category);
CREATE INDEX idx_moderation_log_flag ON moderation_log(flag_id);
CREATE INDEX idx_moderation_log_admin ON moderation_log(admin_id);
CREATE INDEX idx_audit_logs_admin ON audit_logs(admin_id);
```
